▤ Description

The Git panel's base rule `.ph-git button{color:inherit}` out-ranked every single-class rule below it, so branded controls such as `.ph-primary` kept their brand-coloured fill while their label was repainted with the theme's body colour, producing apparently empty buttons. The rule now uses `:where()` to drop the specificity, letting `.ph-primary`, `.ph-chip`, `.ph-filter` and the rest apply their own colours. ## Testing - `shoot.mjs` extracts the `GIT_CSS` block from `HEAD:plugin/dist/client.js` (before) and the working-tree `plugin/dist/client.js` (after). - Screenshots were captured with headless Chrome.
